# 台股空方現股當沖 A／B｜隔離回測先行

**此研究 PR 只評估歷史交易淨損益，不修改 Jacky168168 正式首頁、選股邏輯、A/D/F/G/G Pro 或 Risk Score。**

## 研究定義

A 弱勢延續：前5交易日個股相對加權指數弱勢至少3個百分點，今天開盤±1%，開盤前15分鐘區間形成後，09:15～11:00的已完成5分K跌破區間低點、低於當日近似 VWAP，同時間進度相對量≥1.5。

B 開高假突破：開高≥1%，盤中先突破前日高點及開盤區間高點，隨後回落至前高與近似 VWAP 以下，收黑K且相對量≥1.5，下一根才准模擬放空。

共同過濾：前20個交易日平均成交額≥5億元，股價10～300元，前日 ATR14/股價 3%～8%；只用當時已發生的K棒與前一日資料，不用未來收盤資訊。

## 成本與進出場

- 本金100萬元；每筆1張、每檔空方總額≤30萬元、每筆停損風險≤5000元、每模式每天最多3筆。
- 賣與買回各扣完整手續費0.1425%（每邊最低20元），現股當沖賣出稅0.15%，單邊滑價1 tick與2 tick敏感度。
- 訊號5分K收盤後，下根開盤才進場；停損為開盤區間／訊號上影高點上方1tick，停利1.5R，最晚13:20出場。若同根K棒同時碰到兩者，以先停損為保守模擬。
- 各模式分開列出交易數、淨損益、勝率、PF、最大回撤、最差單筆、70/30時間分段。

## 不可省略的限制

- 公開庫現有資料主要是日K與部分盤中快照，不包含全市場一年以上的真實分鐘K，絕不使用日高低價重建不存在的盤中價。
- 先嘗試 Yahoo Finance 免費5分鐘、近60曆日歷史與6個月日K，僅固定30檔研究池；不是全部歷史可先賣後買股票，存在選樣及存活者偏差。
- 未取得逐日「可先賣後買」與暫停名單、真實券商配額，亦未模型化漲停鎖單無法買回及委託簿。報表明確標記 eligibilityByHistoricalDateVerified=false。
- Yahoo 無資料時輸出 NO_RELIABLE_DATA，嚴禁製造任何 PnL；不使用或公開私人 Fugle 授權行情。
- 真正上線前還需要≥1年、理想2年的授權1分K、逐日交易資格及券量；時間獨立的樣本外驗證、完整風險與資金帳。即使短期試算獲利，本 PR **不自動整合正式選股**，需再次審核。
- 資料及結果只在 GitHub Actions 研究檔案，不發布到正式 Pages。
