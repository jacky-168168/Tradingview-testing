# 台股先賣後買當沖：A 弱勢延續 vs B 開高走低／假突破（唯讀回測）

這個研究**只執行真實資料回測**，絕對不更新 Jacky168168 選股頁、不新增交易選股條件、不下單，也不修改現有 G／Risk Score。根據使用者最新更正：「先回測」。

## 行情與限制
- 歷史標的：固定於 2026-10-06 前已存在的站內 A/D 候選名單，加上預先固定的常見流動股票集合，評估 2026-10-07 至 2026-11-26；這是非全市場的試驗樣本，仍有選擇偏差，不能推論全台股。
- Yahoo Finance `yfinance` 的真實 **5 分鐘 OHLCV**，每檔 60 天視窗；缺日線、開收盤或有效 OHLCV 就排除，絕不用日線／隨機價格填補。
- 5 分 K 中的成交價加權典型價格是 VWAP 近似值，不是真正逐筆成交 VWAP；K 內停損與停利先後未知時假設先停損。
- FinMind `TaiwanStockDayTrading` 同檔日期資料可取得時，以 `BuyAfterSale` 當日資格作為個股層級排除。若 API 限權，該筆資格為 **unknown**，不得視為可以做空。經紀商當日額度／券源無法從歷史公開 API 直接驗證。
- 未使用付費／未授權來源、未揭露任何 API Token，GitHub Actions Artifact 只存研究結果，不發布到正式 Pages。

## 事前固定規則
- **A 弱勢延續：** 前 5 個交易日報酬相對 TAIEX 落後至少 3 個百分點、前 20 日平均成交額至少 5 億、日 ATR14／股價 2%～10%、10～1500 元；目前 5 分 K 跌破開盤前 15 分鐘低點、低於當日近似 VWAP、價格弱勢且 RVOL≥1.2，09:15～11:00 觀察。
- **B 開高假突破：** 同樣採成交額、ATR 和流動性濾網，當日開盤比前收高≥1%、當日高點比前收高≥1.5%、後續回落至開盤價及 VWAP 以下、跌破前 K 棒低點並具上影線或高點回落訊號，09:15～11:00 觀察。兩種模式互相獨立。
- **成交：** 5 分 K 確認收盤訊號後，下一根開盤價保守計入賣出不利滑價 0.05%；買回亦計 0.05%。
- **出場：** 最近 3 根 K 棒高點或至少 0.8% 停損、2R 停利，VWAP 重新站回後下一 K 開盤買回，最晚 13:20；同根 K 同時碰到停損、停利時先認列停損。
- **成本：** 手續費未打折，買賣各 0.1425%；當沖賣出證交稅 0.15%；進出各另計 0.05% 滑價。一般回合基準總成本約 **0.535%**。並標記可能觸及漲停導致無法回補的歷史情境，不能用模擬 K 線假設一定能回補。
- 100,000 元名目部位，每天每模式最多取最高訊號一筆；依時間拆分前 60%／後 40%，不拿後段績效反向最佳化參數。收益用單筆與固定名目計算，非真實融資券保證金或交易帳戶報酬。

## 研究結論的硬性門檻
對外僅能稱為「短期 5 分 K 試驗回測」，沒有資料時不印績效；即使短期淨利為正，仍需：
1. 至少 180 個有效交易日、相容的歷史個股可先賣後買資格、可靠的 1 分 K 或逐筆成交資料。
2. 核實券商帳戶、額度、券源及停損回補，避免賣出無法回補／漲停鎖住。
3. 已扣全部成本後，盲測區間具正淨利、足夠交易筆數、PF／最大回撤合理，並通過不同費率和滑價壓力測試。
4. 僅在**額外獲得使用者明確核准**時，才可考慮單獨 PR 加入正式選股功能。
