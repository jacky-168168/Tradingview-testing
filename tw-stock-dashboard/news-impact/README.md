# Global Market Intelligence｜國際國內媒體識別器

## 目的與架構
將新聞標題中具有明確市場傳導機制的事件，轉成台股、美股、NASDAQ、黃金、白銀、WTI 原油、美元、美債殖利率與銅的條件式方向假說。**不是情緒分析，也不是股票報酬率預測**。

- 前端：docs/news-impact.html + docs/news-impact.js。讀取已有的 docs/data/market_events/latest.json，分辨新聞地區、事件、資產、方向、反向條件。
- 歷史封存：news-impact/history.py。使用原本已收集的新聞標題，封存發文時間及來源；用 Yahoo Finance (yfinance) 的已完成日K追蹤。
- 產出：docs/data/news_impact/history.json。工作流程首次成功後才生成，沒資料就明示無歷史樣本。
- 每日 08:27、20:27 台灣時間執行 GitHub Actions；排程可能延遲。與 G 選股和風險分數互不依賴。

## 分數定義
- -100 至 +100 是研究規則的方向強度，不是獲利機率、報酬、勝率或下單指令。
- 標題未命中具體事件規則時明示未判定，不將模糊新聞強判多空。
- 多個事件規則方向衝突時明示衝突；0 不等於零影響。
- 傳聞、計畫、評論、未證實或條件式語句降級可信程度。
- 目前不取得新聞全文，不能宣稱標題已經過獨立事實查核。

## 價格驗證（描述性，非因果）
1. 將新聞發表時間轉換至目標市場時區。
2. 為避免發表當日行情的前視偏誤，取發文當地日期後第一個已完成交易日收盤價作為基準。
3. 計算此基準再往後 1、5、20 個已完成交易日之收盤變化。未成熟的日期不填數據。
4. 因排除新聞當日與跳空初始行情，這是**後續走勢**，不是完整消息瞬間反應。
5. 期貨連續合約可能受換倉、特殊交易時間影響；Yahoo 資料缺漏會明確報錯。
6. 同一新聞可能有不同標題的跨媒體重複報導，不能直接當獨立歷史樣本計算勝率。

## 維運
- 手動執行 workflow: Global Market News Impact。
- 單元測試命令：python -m unittest discover -s tw-stock-dashboard/news-impact -p 'test_*.py' -v
- 生成命令：python tw-stock-dashboard/news-impact/history.py（須先安裝 yfinance）。
- GitHub Pages 與儲存庫公開，禁止放入密碼或 API key。
- 行情來源失敗時保留既有已驗證資料，並標示 priceErrors，不使用虛構資料。

## 下一階段研究方向
- 連接 FOMC、CPI、NFP 等官方發布，加入實際值與市場共識的 surprise 差。
- 同事件類型歷史事件窗：1/5/20 日相對市場報酬、無事件對照組、bootstrap 信賴區間與時間樣本外驗證。
- 加入預期已反映程度、VIX、殖利率、美元、產油供應與衰退條件。
- 建立多來源交叉查證、同事件合併、事後更正、來源可信程度，避免報導數量當成實質新事件數。


## V2：官方日期歷史事件研究（已接入獨立頁）
- 研究頁：docs/news-impact-history.html；JS：docs/news-impact-history.js。
- 可溯源日期：news-impact/official_events.json，目前按聯準會利率調整生效日、BLS CPI 公布日、OPEC 原始公告與美國選舉日期建立研究日曆。並非每場 FOMC 例會都列入；僅列官方紀錄中的利率實際變動。
- 研究引擎：news-impact/official_study.py。讀 Yahoo Finance 完成日K；預設過去五年；輸出 docs/data/news_impact/official_study.json。無資料或未成熟時，不填假值。
- 美國股票／台股：若已知當地公布時間早於該市場正常收盤，允許用當日收盤計量；晚於收盤則採下一個有效交易日。期貨、指數代理及僅日期事件採隔日起完整K線，避免誤將尚未公告時的收盤價當作事件後。
- 報酬為首次可計入交易日前一個收盤價至第 1/5/20 個已完成交易日收盤的變化；注意期貨結算、跨市場時區與假日均可能讓事件窗較粗糙。
- 每種事件類型 × 商品的有效事件個數 n、平均值、中位數、正報酬占比、事件窗的全部一般滾動期間平均差；n < 5 明示樣本不足，不顯示百分比為主的摘要。這不是因果對照組，也不是預測勝率。
- FOMC 例會公告日使用聯準會生效日期前一天的保守推定，標示 inferred_regular_meeting；已知 CPI 官方時刻為紐約 08:30；OPEC／選舉 date_only 不擅自補發布時刻。
- 特別重要：CPI 的當時市場預期與實際值差尚未接入，因此目前 **無法判斷 CPI 高於或低於預期**；不做虛構超預期交易回測。
- 除日期外不含市場預期、單一新聞因果確認、政策屬性保證、實盤訊號；OPEC 會議日期不代表市場第一次知道消息。
- 測試：python -m unittest discover -s tw-stock-dashboard/news-impact -p 'test_*.py' -v，會隨 GitHub Actions 執行。
- 原新聞追蹤與歷史研究是不同資料流；後者的 40 筆日期不等於 40 個統計上獨立或方向可比較的樣本。

## 已知待改善
- 官方日期目錄是人工核對來源的起始版本，非持續更新的全部官方事件日曆；新增日期需附來源與重新驗證。
- OPEC 和選舉有效樣本較少，且時間高度聚集；不能從正報酬率推論因果。
- 目前不支援官方「超預期程度」量化，需專門的當時可觀測共識預測資料，之後才能做 surprise study。
- 後續要加同一事件跨媒體合併、來源可靠性記錄、彭博/路透有授權全文語意判讀（不擅自擷取付費全文）。


## V1.1：截圖新聞誤判修正（2026-11-09）
- 新增 docs/news-impact-sector.js 與 news-impact/test_sector.cjs，CI 會執行 Node.js 分類回歸測試；HTML 加入版號以降低手機快取舊 JS 的問題。
- 記憶體／DRAM／DDR5／NAND **產品報價** 上漲／下跌時，新增「台股記憶體供應端」條件式方向，不外推整體加權指數。股價下跌、傳聞、漲跌混雜與沒有產品報價依據時不強判。
- 以色列「授權組閣」是政治事件，並不等於停火、戰爭升級或能源供給中斷；辨識事件類型但不亂給黃金／WTI 的利多空分數。
- 紐西蘭選情相關新聞如直接說「紐元已上漲」，獨立標示為**新聞已報導的市場反應**，不當成未來走勢預測，也不混入多空分數統計。
- V1.1 仍是明確條件下的可稽核規則模型，不是經過訓練的全文語意 AI，也不能保證所有標題可判。無可驗證傳導關係時，允許保留未知。
