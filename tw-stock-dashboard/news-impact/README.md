# Global Market Intelligence｜國際國內媒體識別器

## 目的與架構
將新聞標題中具有明確市場傳導機制的事件，轉成台股、美股、NASDAQ、黃金、白銀、WTI 原油、美元、美債殖利率與銅的條件式方向假說。**不是情緒分析，也不是股票報酬率預測**。

- 前端：docs/news-impact.html + docs/news-impact.js。讀取已有的 docs/data/market_events/latest.json，分辨新聞地區、事件、資產、方向、反向條件。
- 歷史封存：news-impact/history.py。使用原本已收集的新聞標題，封存發文時間及來源；用 Yahoo Finance (yfinance) 的已完成日K追蹤。
- 產出：docs/data/news_impact/history.json。工作流程首次成功後才生成，沒資料就明示無歷史樣本。
- 每日 08:27、20:27 台灣時間執行 GitHub Actions；排程可能延遲。與 G 選股和風險分數互不依賴。

## 分數定義
- -100 至 +100 是研究規則的方向強度，不是獲利機率、報酬、勝率或下單指令。
- 標題未命中具體事件規則時明示未判定，不將模糊新聞強判多空。
- 多個事件規則方向衝突時明示衝突；0 不等於零影響。
- 傳聞、計畫、評論、未證實或條件式語句降級可信程度。
- 目前不取得新聞全文，不能宣稱標題已經過獨立事實查核。

## 價格驗證（描述性，非因果）
1. 將新聞發表時間轉換至目標市場時區。
2. 為避免發表當日行情的前視偏誤，取發文當地日期後第一個已完成交易日收盤價作為基準。
3. 計算此基準再往後 1、5、20 個已完成交易日之收盤變化。未成熟的日期不填數據。
4. 因排除新聞當日與跳空初始行情，這是**後續走勢**，不是完整消息瞬間反應。
5. 期貨連續合約可能受換倉、特殊交易時間影響；Yahoo 資料缺漏會明確報錯。
6. 同一新聞可能有不同標題的跨媒體重複報導，不能直接當獨立歷史樣本計算勝率。

## 維運
- 手動執行 workflow: Global Market News Impact。
- 單元測試命令：python -m unittest discover -s tw-stock-dashboard/news-impact -p 'test_*.py' -v
- 生成命令：python tw-stock-dashboard/news-impact/history.py（須先安裝 yfinance）。
- GitHub Pages 與儲存庫公開，禁止放入密碼或 API key。
- 行情來源失敗時保留既有已驗證資料，並標示 priceErrors，不使用虛構資料。

## 下一階段研究方向
- 連接 FOMC、CPI、NFP 等官方發布，加入實際值與市場共識的 surprise 差。
- 同事件類型歷史事件窗：1/5/20 日相對市場報酬、無事件對照組、bootstrap 信賴區間與時間樣本外驗證。
- 加入預期已反映程度、VIX、殖利率、美元、產油供應與衰退條件。
- 建立多來源交叉查證、同事件合併、事後更正、來源可信程度，避免報導數量當成實質新事件數。


## V2：官方日期歷史事件研究（已接入獨立頁）
- 研究頁：docs/news-impact-history.html；JS：docs/news-impact-history.js。
- 可溯源日期：news-impact/official_events.json，起始版本按聯準會利率調整生效日、BLS CPI 公布日、OPEC 原始公告與美國選舉日期建立研究日曆；擴充版本另收錄歷年 FOMC 政策聲明，包括未調整利率的會議。
- 研究引擎：news-impact/official_study.py。讀 Yahoo Finance 完成日K；使用 Yahoo Finance 可取得的最長日K歷史（period=max）；輸出小型摘要 docs/data/news_impact/official_study.json，逐筆明細另按事件類別與資產分檔至 docs/data/news_impact/official_details/。無資料或未成熟時，不填假值。
- 美國股票／台股：若已知當地公布時間早於該市場正常收盤，允許用當日收盤計量；晚於收盤則採下一個有效交易日。期貨、指數代理及僅日期事件採隔日起完整K線，避免誤將尚未公告時的收盤價當作事件後。
- 報酬為首次可計入交易日前一個收盤價至第 1/5/20 個已完成交易日收盤的變化；注意期貨結算、跨市場時區與假日均可能讓事件窗較粗糙。
- 每種事件類型 × 商品的有效事件個數 n、平均值、中位數、正報酬占比、事件窗的全部一般滾動期間平均差；n < 20 明示樣本不足，不顯示百分比為主的摘要。這不是因果對照組，也不是預測勝率。
- FOMC 例會公告日使用聯準會生效日期前一天的保守推定，標示 inferred_regular_meeting；已知 CPI 官方時刻為紐約 08:30；OPEC／選舉 date_only 不擅自補發布時刻。
- 特別重要：CPI 的當時市場預期與實際值差尚未接入，因此目前 **無法判斷 CPI 高於或低於預期**；不做虛構超預期交易回測。
- 除日期外不含市場預期、單一新聞因果確認、政策屬性保證、實盤訊號；OPEC 會議日期不代表市場第一次知道消息。
- 測試：python -m unittest discover -s tw-stock-dashboard/news-impact -p 'test_*.py' -v，會隨 GitHub Actions 執行。
- 原新聞追蹤與歷史研究是不同資料流；原始的 40 筆人工整理日期與大規模資料更新日期是不同層級；大量 ALFRED 修訂日不能冒充首次公布事件，也不是獨立或方向可比較的樣本。

## 已知待改善
- 官方日期目錄是人工核對來源的起始版本，非持續更新的全部官方事件日曆；新增日期需附來源與重新驗證。
- OPEC 和選舉有效樣本較少，且時間高度聚集；不能從正報酬率推論因果。
- 目前不支援官方「超預期程度」量化，需專門的當時可觀測共識預測資料，之後才能做 surprise study。
- 後續要加同一事件跨媒體合併、來源可靠性記錄、彭博/路透有授權全文語意判讀（不擅自擷取付費全文）。

- 紐西蘭選情相關新聞如直接說「紐元已上漲」，獨立標示為**新聞已報導的市場反應**，不當成未來走勢預測，也不混入多空分數統計。
- V1.1 仍是明確條件下的可稽核規則模型，不是經過訓練的全文語意 AI，也不能保證所有標題可判。無可驗證傳導關係時，允許保留未知。

## V2.1：多年代官方日期與歷史經濟資料更新事件（2026-11-09）
- 自動下載並去重：news-impact/collect_official_events.py 擷取 BLS 原始歷史公告連結與聯準會歷年 FOMC 聲明，使用官方原始 URL 及日期去重；來源失敗時保留前一次有效資料，並輸出 sourceErrors。
- BLS 官方網站在 GitHub Actions 環境回傳 HTTP 403，因此不能宣稱「已匯入全部 BLS 原始公告」。透過 news-impact/collect_alfred.py 改收集聖路易聯準銀行 ALFRED 提供的 CPI／非農／PPI／GDP／PCE／JOLTS／零售銷售／工業生產的歷史 release-date vintages。
- ALFRED 日期可能是任一所屬序列的更新或修訂，未必是經濟統計首次發布；因此獨立分類為「CPI資料更新」、「非農就業資料更新」等，不與人工核對 BLS 原始公告的 CPI 類別混同。
- 目前初步取得逾六千筆來源日期，目錄從 1940 年代延伸至 2026 年，但**不代表六千個獨立政策驚喜或方向可判的事件**。
- 重要防錯：只在事件發布日期與可用行情第一根日K相差不超過 14 天時，才計算 1／5／20 個交易日的描述性報酬；禁止用 1940 年事件去配對數十年後的第一根股票行情。
- 檔案體積管控：前端下載單一摘要 JSON，再依事件類別與選擇的資產載入個別分片，不一次下載所有歷史新聞。GitHub Actions 會一起提交分片。
- 市場研究數據有部分日期重疊、經濟資料修訂與多項外生因素，且未收集市場當時共識值，不得當作有監督的「利多空預測準確率」。小樣本門檻為 20，仍非統計上的顯著性驗證。
- 後續若有可靠且可重製的首次發布日期／當時公布值／事前共識值，才可將日期分類升級為真正的經濟 surprise 樣本；既有 ALFRED 類別不能直接更名為 CPI/NFP surprise。


## V1.2：多領域辨識＋前瞻凍結勝率（2026-11-09）
- 識別器額外載入 docs/news-impact-taxonomy.js。先辨識事件主題，再區分「已報導價格變動」、「有市場機制的條件式產業／資產方向」與「僅能辨識主題」；不因標題含金融詞就強迫預測。

- 修正幾種關鍵誤判：升息『押注降溫』及『升息兩難』不等於正式升息；天然氣田停產不等於 WTI 原油減產；60.167 美元是 DRAM 報價單位，不能看成美元指數訊號；標題說黃金『已上漲』是觀察，不是未來黃金預測。

- 僅有九種 Yahoo Finance 交易代理商品能進入勝負驗證。產業板塊（如台股記憶體／AI 設備）與已報導的行情沒有對應可直接交易且已驗證的時間序列，不能混入勝率分母。

## V1.3：新聞識別語意稽核與可累積的前瞻勝率（2026-11-09）
- 新增 docs/news-impact-taxonomy.js 規則強化：辨別新聞標題直接描述的已實現行情、尚未實現的預測、經濟數據的預期差、政治談判進程與產業基本面。新聞主題可識別不代表必定能推估漲跌。
- 修正誤判：記憶體「明年」價格展望和下游企業庫存，不再直接當成記憶體供應端股價利多；伊朗和談傳聞加上已報導的原油跌幅，不再當作新的 WTI 下跌預測；天然氣設施停產應表述為「天然氣價格」可能上行，而非「天然氣供應」利多。
- USD 報導「美元走揚、升息預期提高」現在會區分前者為已實現市場行情、後者為前瞻預期。另加入港幣 HKD 的新聞行情辨識，不憑空新增 HKD 買賣模型。
- 每筆未給方向的新聞顯示缺乏哪種證據（例如尚無首次官方公告、缺失市場共識、僅政治討論、只是產業長期展望），而不是全部以同一段「無法判定」打發。
- news-impact/audit_recognition.cjs 將當批新聞分成：條件式方向、已報導行情、事件機制但方向不足、僅標題主題、僅來源分類、完全未識別。輸出 docs/data/news_impact/recognition_audit.json；**分類涵蓋率不是模型準確率或勝率**。
- news-impact/freeze_signals.cjs 仍只封存事前條件式方向且有對應可追蹤標的的訊號。新分類版本不改寫已封存舊版本的方向與分數；排除已實現行情冒充預測。
- news-impact/scorecard.py 新增 docs/data/news_impact/outcome_ledger/YYYY.json 年度不可逆覆寫結果帳本：成熟後的第一筆方向結果會保存；原始新聞封存超量移除、或行情來源後續修訂時，不自動改寫過去已發表的勝負結果。不同模型版本以原始 frozenAt 和 classifierVersion 追溯。
- 勝率門檻：同標的同期間至少 30 筆成熟勝負，且跨至少 20 個不同發文日，才顯示描述性的方向符合率與 Wilson 區間；不是因果關係證明或扣交易成本後的策略勝率。2026-11-09 當時只有 2 則凍結紀錄與 0 筆成熟結果，不能宣稱已有可信勝率。
- 自動化：原本 GitHub Actions 08:27／20:27（台灣）會依序執行 Node 邏輯防錯測試、Python 單元測試、封存行情、涵蓋率稽核、凍結前瞻方向、成熟結果入帳、更新研究頁。這是固定排程，不代表模型權重自己重新訓練。
- 未完成：報導全文語意判讀、多來源同事件合併與事實核查、交易成本的真實可執行回測、歷史事件市場共識資料與可校準的 ML 分類器。不可把 ALFRED 的資料修訂日期當作前瞻新聞預測樣本。
