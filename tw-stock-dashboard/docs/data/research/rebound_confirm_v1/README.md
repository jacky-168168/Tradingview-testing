# 大跌後反彈確認 — 研究試行版 V1

## 與正式風控分開
- 正式的 `risk.score`、Risk ON/OFF、G／A／D／F／F2 及全部策略買入門檻完全不變。
- 主頁獨立顯示「校正參考」（不是策略分數），只用來說明大跌後反彈有無修復。
- 校正前提皆是**訊號收盤時已知**的資料：前一日指數跌幅、當天指數漲跌、近5日報酬與當日外資買賣超。

## 固定初版規則（需後續樣本外驗證）
1. 前一交易日指數跌幅 ≤ -1.5%。
2. 本日上漲且未完全收復前一交易日跌幅。
3. 本日近5日累計報酬仍為負。
4. 同時滿足 1～3，原始分數保留，參考分數減 10；若本日外資仍賣超，改減 15。
5. 若任一來源無法核對，顯示「校正待確認」，不得當成已通過反彈風險審查。
6. 特殊型態獨立呈現；`Oversold Watch` 不等於 `Strong Bottom Reversal`。

以上下修額度是**待驗證的呈現參數**，並非統計優化權重，也不代表任何量化投資優勢。

## 歷史風險檢查（僅初步，不可宣稱策略獲利）
資料：`g_regime_3y/market_risk_daily.json`，2023-10-11 至 2026-10-08，共 728 個正式交易日。

- 原始正式分數 ≥60 的樣本 400 次，下一交易日加權指數平均 +0.189%，下跌占比 40.8%。
- 同時滿足「前日跌幅 ≤-1.5%、隔天反彈但沒有收復、近5日仍跌且正式分數 ≥60」的樣本 **4 次**，下一交易日平均 **-0.931%**，其中 **3/4 次下跌**。
- 四筆：2025-08-21（隔日 -0.825%）、2025-09-30（隔日 +0.63%）、2026-03-05（隔日 -0.22%）、2026-06-09（隔日 -3.31%）。
- 這是檢視 2026/10/14 事件後提出的假說，**具有事後挑選偏誤**。單次市況波動、樣本稀少，不能宣稱可靠預測勝率或降低實際 G 選股最大回撤。
- 正式推動 G/F2 交易門檻前，必須做資料時序確認、依時間切分樣本外回測、包含交易成本、回撤及錯失 V 型反轉的損失。

## 2026/10/14 的例子
10/13 -1.95%，10/14 +0.59%、近5日 -2.40%、外資淨賣超 200.4 億，原始 70 → 校正參考 **55**；狀態「反彈待確認」。不以事後 10/15 的 -3.41% 當作當天已知資訊。

## 2026/10/15 的例子
正式 21 分，中文市場風險區間「極高風險」；底部 `Oversold Watch`（超跌 4、Bottom 確認 0）顯示「超跌觀察｜反轉未確認」。不可將低分稱為「極度恐慌」或把超跌誤當成確認買點。

資料限制：市場風險五段分類只是可讀的操作語言；並非獨立恐懼／貪婪情緒測量指標。
