# H5 選股不變，改為最多五次等額加碼｜2026 回測

**狀態：GitHub 研究分支，尚未合併到 main 或正式網站。** 研究日：2026/1/1～2026/10/7。

## 選股完全沿用已研究的 H5 固定版本
從 `research/h-v5-limit-pullback-2026` 保留原版 `features`、`mask_family`、`score` 的特徵和公式；選用先前固定測試過的 `fresh_break` 強勢突破組：
- 股票收盤價 >= 12 元，成交額 >= 1 億元；
- 當天估算週轉率 >= 5%、前五日平均估算週轉率 >= 0.4%、當日交易量相對**前20日** >= 2 倍；
- 收盤高於前20日高點 3% 以上；當日漲幅介於 1%～9.5%，收盤位於當日高低區間上方30%；ATR14 >=2%；
- 母池還有股價 >=12、交易額 >= 6500 萬、估算週轉率 >=0.7%、量比 >=0.7 等前置條件（由上述正式條件覆蓋）。
- 每天依 `0.4×前5日平均估算週轉率＋20日漲幅/6＋ATR14/2＋突破20日高點幅度/8` 排名，取 Top3。
- 完全不取用 A/D/F/G 的排名、選股條件或風險濾網。

## 更正後進場與出場規則
1. **第一筆**：以 G? 不，**H5 訊號當日收盤價的 -2%、-2.5% 或 -3%** 放下一交易日有效的買單。若開盤跳低，依實際開盤價成交；若隔天始終沒觸及限價，放棄該筆訊號。
2. **第二～五筆**：以第一筆**實際成交價 P1** 為基準，在 P1×0.98、P1×0.96、P1×0.94、P1×0.92 設定四筆預先固定的加碼買單；未成交買單可在持有期限內繼續等待。
3. 每筆分配等額資金（五筆總預算=100%，每筆20%），不保證都有成交；持有股數依各筆實際買價換算，平均成本為**總買進成本／總股數**。
4. 加碼後隨最新平均成本同步調整：**+7% 毛停利、-15% 毛停損**。首次入場後最長測試 5、10、20 個交易日，屆期沒有達標則收盤出場；未使用的預算保留現金。
5. 模擬手續費買賣各0.1425%、證交稅0.3%、買賣滑價各0.1%。台股日K當天如加碼限價盤中成交，*不把同日高點視為可獲利停利*，但低點可優先觸發停損；空頭跳空以開盤價出場。
6. **這是每筆選股事件回測，不是可直接用於實盤的帳戶績效**：同一股票多次出榜與不同股票同時建倉未做資金占用、風控與融資/信用額度約束。最多五次加碼可能導致虧損時的投入金額更大。

### 價格例子
訊號收盤 100 元，第一筆 -2.5%=97.50 元且剛好成交：
|筆數|限價（元）|依第一筆實際成交價|
|---|---:|---|
|1|97.50|-|
|2|95.55|-2%|
|3|93.60|-4%|
|4|91.65|-6%|
|5|89.70|-8%|

**平均成本不能固定用五筆算術平均**：只有真正成交的筆數才算；且每筆買進的是等額資金而不是等股數，故採實際總股數加權平均。

## 必須注意的歷史資料限制
- 週轉率分母是**目前資本額/假設面額10元**估計，非歷史真實流通股本；2026股票池也有倖存者偏差。
- 日K的 OHLC 無法確認盤中是否先觸發不同檔位、先停損還是先停利；研究採保守順序，但與真實成交仍可能不同。
- 大額加碼實務涉及成交量、價差、跳空、跌停無法出場等風險；-15% 並不保證實際損失限制在 -15%。
- 2026已反覆被用於先前 H1-H5 策略研發，這不是獨立樣本外測試。上表的高達標率不能當成可保證勝率。
- **沒有完整帳戶層級投資組合績效**，因為多筆新訊號會與仍持有/加碼的部位同時爭用資金。任何「每天買 Top3」需要額外的共同資金限制和去重。
